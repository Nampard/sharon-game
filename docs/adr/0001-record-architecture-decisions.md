# ADR-0001: 아키텍처 결정을 ADR로 기록한다

- 상태: 승인됨 (Accepted)
- 날짜: 2026-11-25

## 배경

웹캠 기반 "무궁화 꽃이 피었습니다" 게임은 인식 모델, 움직임 판정 기준, 패키징 방식처럼
나중에 바꾸기 비싼 결정이 많다. 결정의 이유가 남아 있지 않으면 같은 논의를 반복하게 된다.

## 결정

- `docs/adr/NNNN-제목.md` 형식으로 번호를 붙여 기록한다.
- 각 문서는 **상태 / 배경 / 결정 / 결과(트레이드오프)** 를 담는다.
- 상태: `제안됨(Proposed)` → `승인됨(Accepted)` → 필요 시 `대체됨(Superseded by ADR-XXXX)`.
- 승인된 ADR은 고치지 않고, 결정을 바꿀 때는 새 ADR을 쓰고 이전 것을 "대체됨"으로 표시한다.

## 결과

- 새 결정을 내릴 때 문서 한 장이 늘어나는 비용이 든다.
- 이 프로젝트를 이어받는 사람(또는 Claude)이 "왜 이렇게 했는지"를 코드 밖에서 확인할 수 있다.
