# ADR-0005: 게임 흐름은 상태 머신, 화면·사운드는 pygame으로 처리한다

- 상태: 제안됨 (Proposed)
- 날짜: 2026-11-25

## 배경

게임은 "구호 외치는 중(움직여도 됨) ↔ 뒤돌아봄(멈춰야 함)"이 반복되고,
탈락 시 총소리·화면 효과가 즉시 나와야 한다. 구호 속도가 매 라운드 달라야 긴장감이 생긴다.

## 결정

### 상태 머신

```
TITLE → LOBBY(참가자 등록) → CALIBRATE(보정, 선택) → COUNTDOWN
      → [ GREEN(구호 재생, 움직임 허용) ⇄ RED(뒤돌아봄, 움직임 판정) ]* → RESULT
```

- `GREEN`: "무궁화 꽃이 피었습니다" 구호 재생. 재생 속도를 라운드마다 무작위(0.7×~1.6×)로 바꾸고, 가끔 중간에 멈칫하는 페이크를 넣는다.
- `RED`: 2~4초 무작위 지속. 이 상태에서만 ADR-0004 판정이 동작한다.
- 탈락 이벤트: 총소리 재생 → 해당 참가자 박스 빨간색 + "탈락 #번호" 표시 → 화면 흔들림/플래시.
- 승리 버튼이 눌리거나(ADR-0004), 모두 탈락하거나, 제한 시간이 끝나면 `RESULT`.
- 프로토타입에서는 `CALIBRATE` 대신 디버그 오버레이(실시간 score 표시)와 `+`/`-` 키로 임계값을 현장에서 조정한다. 자동 보정은 이후 추가.
- 구호 속도는 리샘플링(음높이도 함께 변함)으로 만든다.
- 난이도 장치(술래 규칙, `config.Rules`, 난이도별 `DIFFICULTIES[...]["rules"]`):
  - **구호 끊기** `fake_chance`: 구호를 40~75% 지점에서 끊고 바로 돌아본다 (첫 라운드 제외).
  - **재확인** `snap_chance`: RED가 끝나고 돌아선 뒤 0.35~0.7초 만에 다시 돌아본다 (이벤트 `snap`). 일찍 움직인 사람을 잡는다.
  - **가속** `accelerate`: 2라운드마다 가장 느린 구호 속도를 후보에서 뺀다 (최소 2개 유지).
  - RED 지속 시간 범위 `red_min_s~red_max_s` 는 난이도가 높을수록 넓어진다.
- 난이도는 쉬움/보통/어려움/지옥 4단계 (제목·등록 화면에서 1~4 키).

### 스레드 구조

```
[카메라 스레드] → 최신 프레임 ─┐
                               ├→ [인식 스레드: YOLO + 추적] → 최신 Person 목록
[게임 루프(메인, pygame 60fps)] ← 최신 프레임 + 최신 Person 목록 읽기
        └ 상태 머신 / 판정 / 렌더링 / 사운드
```

- 스레드 간에는 "최신 값 하나만 보관하는" 슬롯(락 + 덮어쓰기)으로 주고받는다. 큐에 쌓지 않는다(지연 누적 방지).
- 판정은 인식 결과가 **새로 들어온 프레임에만** 수행한다 (같은 결과를 여러 번 판정하지 않음).

### 화면·사운드

- pygame으로 전체화면 렌더링: 카메라 영상을 배경으로 깔고 그 위에 참가자 표시, 상태, 남은 시간, 술래 인형을 그린다.
- 시각 언어(`render.py` 상단 토큰): 인주 빨강(멈춤·탈락), 단청 초록(움직여도 됨), 황(승리), 한지색(글자·이름표), 색동(남은 시간 막대).
  강한 장식은 **도장** 하나로 제한한다 — RED의 "멈춰"와 탈락자의 "탈락"이 기울어진 인주 도장으로 찍힌다.
  참가자는 모서리 괄호(조준선) + 한지 이름표, 구호는 소리에 맞춰 한 글자씩 켜지는 가사로 보여 준다(페이크로 끊기면 그 자리에서 멈춤).
- 한글 표시는 번들한 한글 폰트(예: Noto Sans KR, OFL 라이선스)를 사용한다.
- 사운드: `pygame.mixer` 로 구호/총소리/배경음 재생. 구호 속도 변경은 미리 여러 속도 버전을 만들어 두거나 재생 중 리샘플링한다.

## 결과

- 상태 머신이 명확해 "언제 판정하는가"가 한 곳에서 관리된다.
- 렌더링과 인식이 분리돼 인식이 느려도 화면은 부드럽다. 대신 판정은 인식 fps(목표 15fps+)에 묶인다.
- pygame은 UI 위젯이 없어 메뉴/설정 화면은 직접 그려야 한다.
