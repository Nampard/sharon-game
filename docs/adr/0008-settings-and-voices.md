# ADR-0008: 설정 화면과 목소리 폴더

- 상태: 제안됨 (Proposed)
- 날짜: 2026-11-25

## 배경

- 맥에 아이폰(연속성 카메라)이 붙으면 OpenCV 0번 카메라가 아이폰이 되는 등, 어떤 카메라를 쓸지 고를 방법이 필요하다.
- 기계음 구호 외에 실제 지인 목소리를 여러 개 녹음해 바꿔 쓰고 싶다. exe로 배포한 뒤에도 코드 수정 없이 추가할 수 있어야 한다.

## 결정

### 설정 화면 (`settings.py`, 제목 화면에서 S)
- 항목: 카메라 번호, 술래 목소리, 난이도, 제한 시간. 위아래로 고르고 좌우로 바꾼다. 닫을 때 `config.json` 에
  해당 키만 덮어써 저장한다(`save_config`, 사용자가 직접 적은 다른 키는 유지).
- 카메라 이름은 OpenCV로 얻을 수 없어(플랫폼별 API 필요) **번호 + 실시간 미리보기**로 고르게 한다. 설정 중에는
  인식 결과가 아닌 카메라 원본 프레임을 바로 보여 준다. 전환은 `Camera.switch()` (메인 스레드에서 열기 유지).

### 목소리 폴더 (`audio.py`)
- `assets/voices/<이름>/chant.wav`(내장, 기본 "기계음") + 실행 폴더의 `voices/<이름>/chant.wav`(사용자 추가).
  같은 이름이면 사용자 것이 우선. wav/ogg/mp3, 선택 `voice.json`(표시 이름, 글자별 시간 비중).
- 불러올 때 음량 포락선으로 말 구간을 찾아 앞 무음을 자르고 끝은 울림 0.8초만 남긴다. 말 구간(시작·끝)은
  화면 가사 타이밍에 쓴다 → 녹음마다 말 빠르기가 달라도 가사가 맞는다. 비중이 없으면 글자를 균등 분배.
- 목소리가 둘 이상이면 "무작위"(라운드마다 다른 목소리)를 고를 수 있다. 이를 위해 게임은 GREEN마다
  `prepare_chant(speed)` 를 호출해 목소리를 정하고 길이를 받는다.
- 지인 녹음은 개인 정보이므로 `voices/` 는 git에서 제외한다(README만 공유).

## 결과

- 카메라를 이름이 아닌 번호로 고르는 불편이 있지만, 미리보기로 보완한다.
- 깨진 녹음 파일은 건너뛰고 설정 화면에 "불러오지 못한 목소리"로 표시한다.
