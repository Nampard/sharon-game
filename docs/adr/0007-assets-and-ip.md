# ADR-0007: 그림·소리는 직접 만든 자산만 쓴다

- 상태: 제안됨 (Proposed)
- 날짜: 2026-11-25

## 배경

"무궁화 꽃이 피었습니다"는 전통 놀이라 규칙 자체는 누구나 쓸 수 있다.
하지만 드라마 *오징어 게임*의 영희 인형 디자인, 실제 음성, 배경음악, 로고, 폰트 등은 넷플릭스의 저작물/상표다.

## 결정

- 분위기(긴장감, 초록/빨강 신호, 총소리 탈락, 핑크 진행요원 느낌의 색감)는 참고하되, **드라마의 이미지·음성·음악·로고를 그대로 쓰지 않는다.**
- 술래 캐릭터는 직접 디자인한 **색동 한복 소녀 인형**을 쓴다. 기본은 Codex로 생성한 스프라이트(`assets/images/doll/` 뒤·앞·붉은 눈 3장)이고, 파일이 없으면 `src/mugunghwa/doll.py` 가 코드로 그린 인형으로 대체한다. 드라마 인형의 특징(주황 원피스·노란 셔츠·양갈래 머리)은 피한다. 게임 중에는 등을 보이고 RED 때 고개만 돌려 붉은 눈으로 훑는다.
- 구호 음성은 직접 녹음하거나 TTS(라이선스 확인)로 만든다. 현재는 macOS TTS를 구간별 속도·음높이로 가공해 "느리게 끌다 끝을 몰아치는" 리듬과 높은 인형 목소리, 울림을 입혔다(`tools/make_sounds.py`).
- 출처를 확인할 수 없는 유튜브 음원은 내려받아 넣지 않는다.
- 총소리·효과음은 CC0 또는 라이선스가 명확한 소스에서 가져오고, 출처를 `assets/CREDITS.md` 에 기록한다.
- 제목에 "오징어 게임" 상표를 쓰지 않는다 (예: "무궁화 꽃이 피었습니다 – 캠 챌린지").

## 결과

- 학교 행사나 공개 배포 시에도 저작권 문제 없이 쓸 수 있다.
- 자산 제작 시간이 추가로 든다.
