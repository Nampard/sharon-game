# 술래 목소리 추가하기

이 폴더 안에 사람마다 폴더를 하나씩 만들고, 그 안에 녹음 파일을 `chant.wav` 이름으로 넣으면
게임의 **설정(S) → 술래 목소리** 목록에 폴더 이름으로 나타납니다.

```
voices/
  철수/chant.wav
  영희/chant.wav
```

- 문장: "무궁화 꽃이 피었습니다" 한 번. 앞뒤 무음은 게임이 알아서 잘라냅니다.
- 형식: wav 권장 (ogg, mp3도 됨). 휴대폰 녹음(m4a)은 wav로 바꿔서 넣어 주세요.
- 게임을 켠 채로 파일을 넣었다면 설정 화면에서 **R** 을 누르면 다시 읽습니다.
- 목소리가 둘 이상이면 "무작위"를 고를 수 있습니다. 라운드마다 다른 사람 목소리가 나옵니다.
- 화면 가사는 말이 시작하고 끝나는 지점을 자동으로 찾아 글자를 고르게 나눕니다.
  리듬이 특이해서 맞지 않으면 같은 폴더에 `voice.json` 을 두고 글자 10개의 시간 비중을 적을 수 있습니다:
  `{"name": "철수", "weights": [1.2, 1.2, 1.2, 1, 1, 0.6, 0.6, 0.6, 0.6, 0.6]}`

지인 녹음은 개인 정보라 git에 올라가지 않도록 `.gitignore` 에서 제외되어 있습니다.

## 목소리 변조하기 (메가폰 소녀 목소리)

`tools/voicefx` (NAudio, C#) 로 녹음을 변조해 바로 이 폴더에 넣을 수 있습니다.
아래에서 **`~/Downloads/내녹음.m4a` 는 실제 녹음 파일 경로로, `철수` 는 목소리 이름으로** 바꿔서 실행합니다.
macOS에서는 휴대폰 녹음(m4a)을 그대로 넣어도 자동으로 변환합니다.

```bash
tools/dotnet.sh run --project tools/voicefx -- ~/Downloads/내녹음.m4a "voices/철수/chant.wav" --pitch 1.75
```

`--pitch` 는 음높이 배율입니다 (낮은 목소리는 1.7~1.9, 높은 목소리는 1.3~1.5 정도). `--no-megaphone` 을 붙이면 음높이만 바꿉니다.
말 앞에 들숨 소리가 들어갔으면 `--start 1.94` 처럼 말이 시작하기 직전 시각(초)을 주어 그 앞을 잘라냅니다. 메가폰 효과가 작은 숨소리까지 키우기 때문에 게임의 자동 무음 제거만으로는 남을 수 있습니다.
